# 探索性用例

這個目錄裡的用例**不會被 `make eval` 執行**——`LoadCases` 走訪用例目錄時不遞迴
（見 `internal/eval/case.go`），所以放在子目錄底下就自動排除在預設套件之外。

要跑其中一條：

```bash
make eval EVAL_FLAGS="--cases evals/exploratory/07-path-denied-converges.yaml"
```

## 這個目錄存在的理由

預設套件（`evals/*.yaml`）是**回歸閘門**：它每次都該綠，紅了就代表有人弄壞了東西。
一條已知會隨機轉紅的用例放進去，會讓每一個紅燈都變成「大概又是那條飄的」——然後
真的退步發生時，沒有人會去看。

但那條用例量到的東西是真的，刪掉等於把證據丟了。所以放這裡：**保留可複跑的證據，
不佔用閘門的信用。**

## 什麼時候該把一條用例搬回 `evals/`

它的指標在足夠多的樣本上有穩定上界的時候。判準不是「跑三次都綠」——ticket #55
的教訓正是三次全綠之後第四次就爆掉（詳見各用例檔頭記錄的樣本分佈）。
